# 🎛️ ASA Lab — Studio Podcast & Régie Audio Live

> **Version actuelle : `v1.4.0`** • Windows 10/11 (x64) & macOS (Apple Silicon M1–M4 & Intel)

**ASA Lab** est une application de bureau professionnelle dédiée au traitement audio temps réel **ultra-basse latence**, réunissant deux environnements complets dans une seule interface sombre de précision :

---

## 🎙️ 1. Mode Studio Podcast
Pensé pour les podcasts en ligne, le streaming, le jeu de rôle (JDR), Discord, WhatsApp et OBS :
- **Moteur Audio Natif Windows WASAPI Exclusif 3.0 ms** *(0.0 ms DSP, 6.0 ms aller-retour matériel complet)* — fini les 50 à 120 ms de latence des navigateurs.
- **Chaîne voix complète en temps réel (0.0 ms DSP)** : EQ paramétrique 16 bandes, Anti-Bruit adaptatif (NS1 / Clarity Vx), De-Esser, Noise Gate, Compresseur Soft-Knee et Limiteur Broadcast (-14/-16/-18 LUFS).
- **Palette Voix JDR Qualité Studio** : 9 préréglages créatifs temps réel (Démon, Elfe, Robot, Radio, Caverne, Gobelin, Anonyme…) avec Pitch Shifter YIN pitch-synchrone, couche Sub-Octave et sculpteur de formants 3 bandes.
- **Voix de test studio HD (FR & EN)** + **Pilote Virtual Cable intégré** pour router directement votre voix traitée vers Discord, WhatsApp, Zoom ou OBS.

## 🎸 2. Mode Régie Concert (Waves eMotion LV1)
Pensé pour les balances, le live et la scène :
- **Console de tranche complète (18 tranches)** : EQ paramétrique interactif + analyseur de spectre RTA temps réel (20 Hz – 20 kHz) + instruments de test studio remasterisés.
- **Waves X-FDBK (Anti-Larsen)** : détection haute résolution et filtres coupe-bande (notches) chirurgicaux.
- **Auto-Tune Pro (YIN)** : correction de justesse vocale temps réel par gamme, tonalité et vitesse de correction.
- **Assistant IA complet** (avec ou sans clé Gemini) configurant automatiquement tous les plugins + export PDF vectoriel.

## 🔄 Mises à jour automatiques en 1 clic
- **ASA Lab** vérifie automatiquement la disponibilité d'une nouvelle version au démarrage et affiche une notification discrète en bas à droite.
- Depuis **Options → Mises à jour**, la nouvelle version s'installe **directement par-dessus** sans rien désinstaller, en conservant 100 % de vos réglages et préréglages.
